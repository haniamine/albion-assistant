# albion-assistant-mover

Small Windows automation assistant for Albion workflows.

The first script listens for the `&` / `1` key, finds the `take-all` button image on screen, and double-clicks its center.

## Install

From the project folder:

```powershell
pip install -r requirements.txt
```

## Run

```powershell
python scripts\laborer.py
```

Press `Esc` to stop the script.
